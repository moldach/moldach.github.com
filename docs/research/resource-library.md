## Decisions to capture before implementation

| Topic | Decision needed |
| --- | --- |
| Purpose and visitors | What should someone understand about you, and what should they do next? |
| Content | Biography, projects, writing, resume, contact, and which sections actually belong. |
| Visual direction | Typography, palette, density, imagery, page composition, and examples to avoid. |
| Project storytelling | Which work deserves a case study and what evidence can be shown publicly. |
| Assets | Existing photos, logos, diagrams, illustrations, 3D models, and their original sources. |
| Motion | Which interactions communicate something useful, plus reduced-motion behavior. |
| Technology | Choose after auditing the existing repository and clarifying publishing needs. |
| Contact | Decide whether email alone is sufficient or a form is needed, then verify the hosting-compatible submission approach. |
| Quality | Mobile behavior, keyboard navigation, readability, performance, and link integrity. |
